# Spotify Web

A static recreation of the Spotify web player layout, built to practise HTML and CSS.

**Live demo:** https://andreacassini.github.io/html-css-spotifyweb/

## What is in it

- Sidebar with Home, Search, Your Library and Create Playlist
- Playlist list and a recently played row
- Browse sections for podcasts, charts, genres and moods, new releases and discover

## Run

No build step. Open `index.html` in a browser.
